# 晾念头：干净挂绳与按需整理入口设计

状态：旧方案历史。最新用户决定已落实：移除整排工具条，且不增加绳结或另一排图标。实际入口为便签右键临时菜单、已有托盘和快捷写作浮层。后文绳结建议未采用。核心反馈：整排“全部/Codex/Claude/Cursor/通用/筛选Agent/查找”标签让挂绳不干净。保持既有桌面挂绳、紧凑卡片、双端和快捷输入要求。

## 推荐：绳上展示，绳结整理

默认展开只见细绳、彩色夹子和便签；移除上方整排工具栏。Agent归属继续由夹子颜色和便签内的Agent文字识别，不另重复一排Agent按钮和数字。

右端放一个低存在感的细小绳结，视觉约8–10DIP，真实点击区32×32DIP。位置固定，不在鼠标接近时位移/缩放，不铺底板。悬停增强高光并提供“整理念头”提示；点击才显示临时菜单。装饰绳和其余空白仍穿透，只有这个可见绳结及既有便签/夹子命中可交互。

菜单仅包含：筛选Agent（含全部）、查找念头、已收起。Agent列表和计数只在菜单展开时出现，不需要同时保留按钮和下拉列表；设置仍在菜单栏/托盘。选完自动收起菜单。

右键便签提供就近路径：“只看这个Agent”“显示全部”“查看全文”“查找念头”。不要求用户右击整条装饰绳或桌面空白，因为这些区域需要穿透，无法同时作为可靠菜单触发区。

筛选激活时，绳结出现小标记点，菜单中明确勾选当前Agent且提供“显示全部”；不把一排标签重新放回来。标记同时有可读提示，不能只靠颜色。过滤仍不减重。溢出时在绳结旁保留一个轻量“+N”提示或在绳结的可读名称中说明“还有N条”，点击直接查找；N为溢出便签数，不是已收起历史数。

键盘取用继续经现有写作快捷浮层“查找已挂念头”，也可在菜单栏/托盘选择查找；无须再要求记一套快捷键。展示层不抢焦点，只有用户主动点开的临时菜单/查找获得正常系统菜单交互。菜单持锁期间不因普通离开计时收回。

## 不采用的替代方式

把同一排标签仅改为“鼠标一来就整排出现”，仍会盖住绳子、频繁跳动；把全部工具隐藏为桌面空白右键，则与透明穿透冲突；增加常驻侧栏或面板则违反产品形态。入口保留一个可发现的绳结，功能再按需出现，避免整条绳都变成工具条。

## 实施与验证落点

用户评审后更新03/05/11并实施；当前0.0.6仍含旧工具条，不将本文件当作已实现。实现后验证：默认/筛选/溢出均无整排标签；绳结位置和命中稳定；正文复制与右键不互相触发；菜单选择/取消不会误收起；键盘可查找全部；多屏/缩放、减少动态效果、Windows公司实机体验分别记录。
