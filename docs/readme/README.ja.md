<h2 align="center"><a href="https://github.com/NocodeMrLi/thoughtline/releases/tag/v0.0.35">Thoughtline をダウンロード</a></h2>
<p align="center"><sub>macOS Apple Silicon · Windows x64 · 0.0.35</sub></p>

Thoughtline（晾念头）は macOS と Windows 向けのデスクトップメモアプリです。画面上端にポインターを移すとロープとメモが現れ、離すと収納されます。今使う文章は色付きクリップに、ほかのメモはグループ、タグ、カレンダーで整理できます。

<p align="center"><sub>デモは蔓の外観、架空のメモ、中国語の画面を使用しています。</sub></p>

## こんなメモに

- 会議の要点、作業の手がかり、仕事中の短い記録。
- あとで続きを考えたい文章のアイデアや日常の思いつき。
- 繰り返し使うプロンプト、返信文、参考テキスト。

## 書く、吊るす、使う、振り返る

1. **書く**：ショートカットや右クリックで新規メモを開き、グループとタグを選びます。
2. **吊るす**：今必要なメモをロープに掛け、関連する紙を一つのクリップに重ねます。
3. **使う**：全文を開いて読み、編集、コピー、別アプリへのドラッグを行います。
4. **振り返る**：使わないメモはカレンダーに収納し、日付や検索から探します。

### メモと下書きを残す

タイトルか本文のどちらかがあれば保存できます。未確定の内容は下書きとして残し、詳細表示やカレンダーでの編集は短い入力休止後に自動保存されます。

### グループとタグで整理する

仕事、生活、プロジェクトをグループで分け、テーマや用途をタグで示します。フィルターは独立し、併用時は両方に一致するメモを表示します。重なりや位置を保ったまま表示を絞り、タグ名、メモのタイトル、本文の単語からタグを探せます。

### 紙を重ねて一枚ずつ読む

同一グループ内では異なるタグもまとめられます。未分類のメモは同じタグ同士でまとめます。各紙のタイトル、全文、タグ、色、リマインダー、作成日は独立して残ります。ページをめくり、ページ番号からタイトル一覧を開くか、一枚だけ分離できます。

### ロープとカレンダーをつなぐ

互換性のあるロープ上・カレンダー内のまとめ先を検索できます。カレンダーにまとめた紙は、分離後もカレンダーに残ります。クリップで束全体を、紙の上端で一枚を動かせます。自動整列と直近の有効な操作の取り消しに対応。絞り込み・まとめパネルは移動でき、Esc や外側クリックで閉じます。

### 元の作成日から探す

日・月・年を閲覧し、タイトル、本文、グループ、タグや状態で検索します。吊るした紙の日付から対応するメモへ移動できます。束は実際の枚数を表示し、各紙はそれぞれの作成日から見つかります。

### 全文を取り出す

プレーンテキストのコピーやドラッグ後も元のメモは残ります。コピー完了はボタン付近に表示されます。使う場所は自分で選び、他アプリや AI サービスへ自動送信されることはありません。

### 一回のリマインダーを設定する

ベルからシステム通知を予約できます。通知の許可とアプリの起動が必要です。終了中に時刻を過ぎたリマインダーは再起動時に案内されます。

### ロープがいっぱいでも記録する

クリップ数は 4・6・8、初期設定は 6 です。カレンダーへ保存するか、古いメモを収納して掛け替えられます。自分で収納したメモは、再び吊るすまでカレンダーに残ります。

### 内容を残すか削除するか選ぶ

グループとタグを作成、改名、選択候補から除外、復帰できます。通常の分類削除は内容を残して移動します。完全削除では同じダイアログ内で内容一覧を確認し、明示的な確認が必要です。タグの対象は全グループと関連下書きに及びます。既定の「通用」「未分组」は保護されます。

## 最初のメモ

1. `Control + Alt + N`、Mac は `⌃ + ⌥ + N` で新規メモを開きます。設定で変更できます。
2. `Enter` で改行。Mac は `⌘ + Enter`、Windows は `Ctrl + Enter` で確定します。新規メモの `Esc` は下書きを保存して閉じます。
3. 画面上端からロープを呼び出し、紙を開いて全文を読みます。右クリックで新規作成、絞り込み、カレンダー、整理へ進めます。
4. カレンダーのその他メニューに「最近删除」「分组与标签」「存储与设置」があります。

## デスクトップに合わせた見た目

外観設定でクラシックな細い紐、編み込みコットン、軽い蔓を選べます。細い紐は色を変更でき、コットンと蔓は自然な色を保ちます。クリップはタグの色に合わせます。

紙は五つの柔らかな色と、無地・横罫線・破線を選べます。プレビュー後に適用してください。画面は中国語／英語、ライト／ダーク／システム設定に対応します。

## データ、書き出し、削除

メモはローカルファイルに保存します。設定で実際のフォルダーを確認し、移動や JSON バックアップの書き出しができます。移動はコピーと検証後に切り替え、元のコピーを残します。TXT・DOCX はタイトルと本文、JSON はメモの全データのバックアップに使います。

通常削除は「最近删除」から復元できます。完全削除は現在の記録を消去し、最近削除にも通常の取り消しにも残りません。既存の自動バックアップや書き出しは保持します。分類の完全削除はロープ、カレンダー、最近削除、下書きの該当内容を含みます。

更新や機器変更前に独立したバックアップを残してください。古いバックアップの復元や旧版への変更では、現在のデータを保管し、形式の互換性を確認します。

## よくある質問

### グループとタグはどう使い分けますか？

例えば「仕事」がグループ、「日報」がタグです。タグだけなら全グループ、両方なら共通して一致するメモを探します。

### 収納、削除、完全削除の違いは？

収納はカレンダーへ、通常削除は復元可能な最近削除へ移動します。完全削除は現在の記録を消します。分類整理は内容を残して移動する方法が初期選択です。

### アカウントやクラウドは必要ですか？

アプリの使用に Thoughtline アカウントは不要です。現在はローカル保存とバックアップに対応し、機器間の移動はバックアップファイルを利用します。配布リポジトリへのアクセス権とは別です。

### Codex タグは AI に接続しますか？

タグは内容を整理するラベルです。Agent API には接続しません。プロンプトを使うときはコピーやドラッグで取り出します。
