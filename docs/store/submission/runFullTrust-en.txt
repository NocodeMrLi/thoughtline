Thoughtline is a packaged Electron Win32 desktop note application. The runFullTrust capability is required to launch its desktop process and register its packaged COM toast activator for reminder notifications. The app provides a transparent top-edge note shelf, global shortcuts for quick capture, user-initiated copy and text drag, and local note storage and backups. It runs with normal user privileges and does not request administrator elevation. No Thoughtline account or cloud synchronization is required.
