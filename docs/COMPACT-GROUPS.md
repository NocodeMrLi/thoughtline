# 0.0.3 紧凑便签与夹子分组

用户确认：默认160×112DIP，短标题识别，主体点击复制全文，展开进入临时380×360详情。单张无分页，多张保留小页码与薄边，悬停显示‹/›，32×32DIP点击区域，首末禁用，不循环，切换不移动夹子；页码打开标题列表。

夹子移动阈值5DIP；在同Agent目标停留600ms后提示“松开合并”。未达到停留时间、不同Agent、移出/Esc/换屏时不合并。合夹保留独立正文与成员顺序；可以拆出、全拆和撤销。位置归一化保存，舒适中心间距220、最小172，放不下进入溢出不删除。全部挂着便签计重，历史/草稿不计，88DIP封顶；合夹不减重。

数据schema2：独立Clip保存成员、当前张、位置；schema1迁移先保留原始备份，再原子保存。41项单测及应用内DOM/IPC/协议鼠标循环有证据；物理双端体验尚待验收。
