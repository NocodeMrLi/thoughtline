## 继续实施顺序

1. **设置与快捷键**：托盘提供临时设置；录制新键、冲突反馈、先注册新键再持久化，保存失败回撤新键并保留旧键，成功才撤旧键；减少动态效果开关持久化。无托盘新建入口。测试检查实际注册结果/磁盘快照，不仅检查按钮文本。
2. **退出与数据错误**：退出保全当前新建草稿；失败保留浮层与正文；已有编辑退出不覆盖原文。无法恢复的损坏/未知版本/IO错误显示可理解的恢复信息，允许打开数据目录，保留全部原文件，不能静默清空。
3. **正文取用拖放**：与夹子排列分离；提供完整text/plain载荷和保持挂绳的拖放生命周期，取消不改数据、不自动复制。逐目标记录Codex/Claude/Cursor真实字符串接收、附件/拒绝/未测；标准路径不足才做独立系统适配小样。
4. **系统与性能**：手动暂停不被睡眠恢复撤销；公共接口可用范围内抑制全屏普通悬停，不能继承私有CGS。记录多屏/缩放/睡眠和2分钟进程树CPU/RSS；以测量结果决定最小优化。
5. **最终验收收口**：G0/G3–G8及U01–U13按同构建SHA记录双端物理结果与用户接受，失败先修对应路径。公司Windows反馈到达后落实平台修复，不用CI/DOM证明实机手感。

每项采用失败验证→最小实现→相应回归→证据/文档→main提交推送。小型JSON/日志保留以追溯；临时App、临时用户目录、解包缓存不留电脑。未具备凭据或实机的外部验收如实标待验，独立实现继续推进。
