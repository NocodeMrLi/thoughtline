# 晾念头 / Thoughtline：交互特效对照与打磨计划

用户2026-10-08明确强调：功能聚焦，交互特效必须重点做好，学习Tendedero和Edge-Drop，并争取超越参考项目的体验。本文作为03项目方案和05交互契约的追加实施依据；优秀体验需要真实使用评审，不因多写几项动画或自动测试就宣布“超越”。

## 对照源码得到的取舍

Tendedero的LineView.swift整体向屏幕上沿平移，展开使用response 0.42/damping 0.82的弹簧，收回0.22秒；绳子有暗影、细核、亮边和端点淡出。PeggedView.swift新卡从上方进入并轻摆，复制会轻推卡片，金属夹子有渐变和凹槽。原项目还使用周期风摆。Edge-Drop的useAdaptiveSpring.ts采用高刚度临界阻尼，设静止阈值，并适配减少动态效果。这些结论来自保留的源码快照，不等于本机运行参考应用的体验证明。

晾念头保留整绳滑入滑出、细绳层次、金属夹子及连续接续；便签比截图小，需要准确点击，不能直接搬用16°入场、悬停放大或周期风摆。复制用短暂描边确认，分页只轻动文字，合夹反馈绑定真实停留时间。颜色表示Agent，文字识别和按钮命中不随装饰消失。

## 当前0.0.6实施参数

- 整绳展开220ms，采用有限时长临界阻尼曲线；收回160ms ease-in，平移250DIP向顶边收回并淡出。快速反向从当前可见帧接续。
- 下沉360ms，同样采用单调、无越界的临界阻尼曲线；sag仍为min(88,8+6N)。最终值精确停止，隐藏不持续动画。
- 渲染层显隐与绳/夹子高度共享一个rAF时钟。卡片位置用translate3d，不以top/left逐帧布局。操作锁冻结重量和位置。
- 收回开始立即恢复穿透，原生窗体保留至渲染层完成；完成通知带会话号，旧通知不能误关新展开。280ms兜底关闭，睡眠/锁屏/切屏立即隐藏。
- 细绳采用暗影、1.5DIP细核、细亮边与两端淡出；Agent夹子保持12×34视觉和24×44交互范围，增加金属渐变与凹槽。
- 复制成功后才强化描边和现有确认。连续复制重置同一计时器，切换当前张时撤旧提示，卸载清理计时器。
- 合夹同Agent目标出现600ms进度环，达到逻辑停留门槛才“松开合并”；不同Agent没有可合并环。减弱动态效果可取消进度运动，仍等待真实600ms与明确完成提示。
- 翻页文字3DIP/140ms过渡，固定160×112卡片和32DIP底部控件；箭头不复制，点击正文取当前完整文本。正文与夹子不共用横向滑动手势。
- 系统减少动态效果实时响应；用户开关持久化。关闭位移/重量/翻页动画，全部操作和保存规则照常。

## 必须保留的下一轮体验检查

入场轻摆、移夹避让与拆分回位需要在真实桌面录像中评审后再定参数，不能用扩大卡片遮挡或动画重叠来制造“更活泼”。优先验证：小卡片易辨认、合夹可取消、拖动不误复制、正文拖入不误当翻页、切屏不留旧命中区域。不会为完成动画而延迟保存，也不加入无限帧循环。
