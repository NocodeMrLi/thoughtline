## 本版变化

- 右键“合并”列出绳上可见的同Agent其他夹子，显示目标标题及纸张数；绑定右击时当前念头和源夹子，只移动这一张，项目/ID/正文/创建日保留。目标显示合入纸张，原夹子剩余顺序保持；无兼容目标显示可读原因。
- 叠纸夹子的右键“拆分”拆当前一张；单张不显示。展开与日历阅读页保留拆分图标，全部拆开仍在更多并明确张数。
- 拆分先使用全绳现有合法空位；没有独立空位而总容量足够时，172DIP安全间距自动腾位后挂上，作为同一笔可撤销变更。真正满容量时保留手动位置和内容，临时提示提供Thoughtline日历入口。
- 整夹拖动与上缘单张拖放保留；向现有目标合并不需要临时占绳位。可撤销两组关系和位置；项目分组删除不能被撤销复活。保存失败保留原快照并显示错误。
- 自动归位180ms可中断，遵循减少动态效果；主界面仍只有绳、夹子、纸张，纸张不玻璃化。
