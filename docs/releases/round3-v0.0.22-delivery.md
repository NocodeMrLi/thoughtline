## 七项反馈的实现与操作

| 项目 | 前置条件、入口与操作 | 修复后的行为与边界 |
|---|---|---|
| R3-01 自动补位 | 选定容量已满，新建写测试念头点“保存”；合并两个兼容夹子 | 新满绳保存的候选按创建时间由新到旧补位，同时间用稳定ID；编辑不改变顺序。仅当前标签范围可补，草稿、最近删除、主动收起、换下及来源不明旧记录不参与。无候选保留空位。合并及补位同一次提交，IO失败不留下半个操作；撤销一起还原。收起／删除释放整夹时也可补其他等待记录，不把被主动收起的那张复活。 |
| R3-02 换上裁切 | 新建或日历未挂详情→“换上”，查看日期、标签、换下张数，滚动更早目标 | 共用列表改为按内容保留行高，不压缩日期和影响说明；仅列表滚动。保留返回、Esc、外点、键盘及旧目标冲突保护，鼠标移开不关闭表单。 |
| R3-03 提醒底部裁切 | 新建写内容→小铃铛→1小时后，暂不保存；窄窗检查换上和保存 | 按状态区、底栏实际高度调节窗口，不重建编辑会话。350／380／420／480 DIP实测留白17DIP，正文完整描边与控件保留。错误和权限提示计入布局，草稿不提前调度。物理输入法选字仍待验。 |
| R3-04 整理状态按钮 | 不规则间距→右键“自动整理”→再次右键“撤销整理” | 同一位置只有一个整理动作；撤销还原位置，不撤回正文、项目删除或当前页。其他撤销名称分别为“撤销夹子操作”“撤销换上”“撤销挂上”“撤销整理挂上”。 |
| R3-05 容量与比例 | Thoughtline日历顶部三个点→存储与设置→语言与外观→“绳上夹子数量”，选4／6／8 | 默认6，立即成功持久化后生效，独立于未保存快捷键及动态效果草稿。基准160×226DIP：4档尺寸上限1.05倍、6档1倍、8档0.95倍，小屏统一缩放，宽高比例保留。绳端适当外伸且留边、保留浅弧。少量仍居中，数量由选择决定，不因屏幕小自动减档。调低按左右顺序保留前几夹，其余保存为容量等待；叠纸成员及当前页一并保留，调高可整夹补回。 |
| R3-06 材质 | 两端新建／日历／详情／设置，中英／昼夜，提醒和换上面板 | 冷暖层叠、高光边缘、控件／卡片深度，分别适应Mac和Windows。原生桌面混合可用时保留；系统要求实色时界面层次也保留。窗口内部面板Mac模糊22DIP、Windows16DIP，纸和前景文字不滤镜扭曲。已获授权临时关闭两项辅助显示偏好，实际包原生桌面材质7点通过并恢复原设置；用户随后主动关闭的选择保留，参考图品质仍待用户验收，不声称原生NSGlassEffectView。 |
| R3-07 最大化呼出 | 普通未完全最大化为正常对照；完全最大化和独立全屏分别移到顶部 | Mac非激活panel、全屏辅助可见、禁止浮层自身全屏，显示时校正层级。自有前台窗口受控验证：保持340DIP浮层，在当前Space且不抢焦点。用户微信／Codex等完全最大化与真实鼠标路径仍待验收；普通最大化故障未在自有窗口复现。Windows对应独立受控检查，虚拟桌面和物理多屏未替代。 |

数量指夹子容量；同夹叠纸及日历总保存量不受4／6／8限制。用户已选择旧记录不迁入补位队列。新的等待来源及容量分组为schema3可选信息，schema编号相同不证明旧版完整理解它们。

## 验证记录与失败追溯

Mac源码 `npm run verify`：308通过，4项Windows专用跳过，类型检查和构建退出0。几何覆盖1024／1280／1440／1920／2560逻辑宽度×4／6／8共15组。布局、补位、材质及原生窗口工作流已验证；受影响容量9、整理7、拆分菜单12、提醒12、标题独存两入口和纸张拖动回归通过。

修复前的列表压缩、提醒留白不足、两个整理项、全屏Space不参与、实色遮挡及容量契约失败均留证。历史固定绳长与“屏小减数量”测试按新用户契约更新，ID、内容、顺序与持久化检查保留。纸张拖动测试旧视口1200与显示器1440不一致，已改为真实显示尺寸及DOM目标坐标，未据此改产品拖动逻辑。
