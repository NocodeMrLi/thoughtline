## 可以照着操作

建议用临时分组、标签和几张测试念头核对以下动作：

| 前置 → 入口 → 操作 | 预期可见／持久结果 |
| --- | --- |
| 日历 → 更多 → 分组与标签 → 分组 → 删除一项有内容的分组 | 默认选“保留内容并迁移”，仍有“迁移到”；按钮“迁移并删除”。 |
| 默认方式 → 选接收分组 → 迁移并删除 | 原分组消失，正文、日期和草稿保留在接收分类。取消则不修改。 |
| 分组 → 删除 → 选“彻底删除分组及内容” | 接收下拉消失，显示真实总张数、挂绳／日历／最近删除分别数及关联草稿；未勾确认时按钮禁用。 |
| 彻底删除方式 → 查看内容 | 在当前弹窗下方展开清单，没有新窗口；名称、创建日期、所在位置逐张列出，关联草稿单列，更多内部滚动；点“收起内容”折回。 |
| 勾“我已了解，此操作不可撤销” → 彻底删除 | 该分组和其中内容一起从当前记录移除，不进入最近删除；其他分组、混合叠放的非匹配成员、原文及实际位置保留。 |
| 标签 → 删除 → 选“彻底删除标签及内容” → 查看内容 | 删除范围包括各分组使用该标签的全部纸张和关联草稿；清单额外显示分组，不受挂绳筛选缩小。 |
| 正在编辑相关内容时进行彻底删除 | 提示先完成相关编辑；未确认输入不会被悄悄丢掉。相关数据变化后须重新勾选确认。 |
| 删除后翻看日历、挂绳、已移除，并正常退出重开 | 被删除分类、念头、草稿和提醒不会由旧编辑会话或旧撤销重新出现；与删除无关的仍有效单条撤销继续可用。 |
| 浅／深色、中文／英文及缩窄窗口 → 查看内容 | 清单按空间缩短，确认、警告和按钮保持可见；真实窗口尺寸不因展开／收起跳动。 |
| 检查默认“通用／未分组” | 继续保护，不提供删除；空分类仍用简洁的原确认流程。 |

彻底删除不支持普通撤销；已有自动／导出备份保留。这是清除当前App记录，未承诺磁盘安全擦除。你明确重新导入历史备份属于另一次恢复操作。
