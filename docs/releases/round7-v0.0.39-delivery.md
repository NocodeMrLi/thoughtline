# Thoughtline 0.0.39：独立设置窗口与菜单整理

保留 zcode 的设置拆窗、标题/拉伸和托盘/夹子菜单调整；修正备份/迁移自身忙碌误拦、设置与写作共存、日历未确认输入保护、设置窗口偏好通信、原辅助窗口样式和“恢复默认”文字按钮显示。日历更多菜单移除设置入口，原设置内容和数据格式保持。

### 五、照着操作的验收清单

先从本轮 0.0.39 安装包启动；正常更新前，从旧版托盘点“退出”，再安装新版。若只想先用假数据检查，可使用安装包目录内的隔离启动脚本。工具没有替你覆盖现有安装或迁移真实便签。

| 步骤 | 从哪里进入、怎么操作 | 应看到什么 |
| --- | --- | --- |
| 1. 核对版本和托盘 | 右键菜单栏/系统托盘的 Thoughtline 图标。 | 有新建、日历、存储与设置、暂停/恢复、版本号和退出；版本为 0.0.39；新建旁显示当前系统快捷键。 |
| 2. 检查两个设置入口 | 从托盘点“存储与设置”；关闭后，再右键任意夹子，点日历后面的“存储与设置”。 | 两处都打开同一类独立设置窗口，不把日历页面换成设置；重复点不会越开越多。 |
| 3. 检查日历菜单 | 打开 Thoughtline 日历，点右上角“···”。 | 保留最近删除、分组与标签，不再出现“存储与设置”。 |
| 4. 检查共存 | 打开新建窗口，输入一段草稿，再从托盘打开设置；也反过来先在“操作”页改减少动态效果但先不保存，再新建。 | 两个窗口可同时保留；正文、名称、光标及设置修改不丢失；新建不会强迫你放弃设置。 |
| 5. 检查关闭保护 | 设置“操作”页改一项而不保存，然后点设置窗口的 ×。 | 出现保存并关闭、放弃修改、继续编辑的选择；点继续编辑后内容仍在。 |
| 6. 检查原界面和按钮 | 设置里切换中/英文和浅/深色，拉大再缩小；外观→更换挂绳/纸张。 | 标题正常、三个页签和内容可操作；顶层没有返回日历箭头，定制页有返回外观箭头。“恢复默认挂绳/纸张”是完整文字操作，没有突兀浅色底块，小窗口下不被底栏裁掉；点取消不会保存外观预览。 |
| 7. 检查备份和导出 | 数据与备份→导出→备份数据，再分别导出 TXT/DOCX；可先在新建窗口留一段未提交草稿。 | 出现选择位置和成功反馈；备份含最新已确认输入，写作可继续。输入法候选尚未确认时应提示先完成输入，不应默默生成旧备份。 |
| 8. 检查迁移保护 | 新建窗口开着时点更改位置；关闭新建后再点，先测试取消。 | 前者提示先关闭新建，后者取消后目录不变。真正迁移测试建议用隔离数据；成功后旧副本仍在，新位置可重启读取。 |
| 9. 检查暂停和退出 | 托盘暂停/恢复悬停；在新建里写草稿但不挂上，再从托盘退出，重新启动。 | 暂停/恢复文字随状态变化；退出后重开能找回草稿，已有念头仍在。 |
