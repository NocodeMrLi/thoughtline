# Thoughtline 0.0.32 操作验证报告

**0.0.32已私有发布**，Release412225874，10份附件大小和服务端摘要读回一致。本报告对应第五轮R5-18至R5-27追加。新增与受影响功能的双端技术检查已通过；按你最新要求复用未变旧功能证据，没有重新从头测试。你的实际设备和体验验收仍待完成。
## 下载与安装

最终私有下载页：[v0.0.32](https://github.com/NocodeMrLi/thoughtline/releases/tag/v0.0.32)。Mac Apple Silicon 使用 `Thoughtline-0.0.32-mac-arm64.dmg`，Windows x64 使用 `Thoughtline-0.0.32-win-x64.exe`。本轮没有 Intel Mac 包。Mac为本地临时签名、Windows未商业签名，沿用已有交付方式。

先在旧版“存储与设置 → 数据与备份”保存完整备份：0.0.31入口为“导出 → 备份数据”，更早版本使用“导出备份”。正常退出旧版，Mac打开DMG将App拖到Applications后启动；Windows运行安装器并选择现有安装目录。先确认“存储与设置”中版本为0.0.32，再按下表验收。旧数据会迁移到schema4并保留schema3原字节备份；回退旧版应在独立目录用升级前备份，不能让旧版读取器覆盖唯一的新数据。

想先用空白数据试用，可将附件中的隔离启动脚本与对应安装包放同一文件夹。Mac双击 `Start-Thoughtline-Isolated-Mac.command`；Windows在PowerShell运行 `./Start-Thoughtline-Isolated.ps1 -Executable "你的安装目录/Thoughtline.exe"`。先正常退出已有Thoughtline；隔离脚本不替你关闭现有应用。Windows脚本需指定已安装的新版程序；隔离的是笔记数据，安装器仍会替换原程序。Mac隔离数据保留在脚本旁的 `isolated-experience`；Windows保留在 `%LOCALAPPDATA%/Thoughtline-Preflight/0.0.32/user-data`，与个人数据分开。

下载的Mac脚本若提示无执行权限，在它所在文件夹打开终端，先执行 `chmod u+x ./Start-Thoughtline-Isolated-Mac.command`，再双击或执行 `./Start-Thoughtline-Isolated-Mac.command`。[Apple执行权限说明](https://support.apple.com/en-ca/guide/terminal/apdd100908f-06b3-4e63-8a87-32e71241bab4/mac)。Windows若默认策略阻止脚本，在附件所在文件夹执行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\Start-Thoughtline-Isolated.ps1" -Executable "你的安装目录\Thoughtline.exe"`；该参数只用于这次进程，不改持久执行策略。[Microsoft会话执行策略说明](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_execution_policies?view=powershell-5.1)。

## 明天可以照着操作

建议先创建“工作”“生活”两个分组和红、蓝两个标签，再创建六张测试念头；名称与正文各自不同，其中至少两张属于工作但标签不同，另两张未分组且同标签。一张先收起到日历。只用测试念头验证删除、拆分与撤销。

| 检查 | 入口和操作 | 应看到的结果 |
|---|---|---|
| 分组作为组织底座 | 将工作组红、蓝标签纸张合并；再尝试跨组及未分组异标签合并 | 同组跨标签允许；跨组拒绝；未分组只同标签允许。名称、正文、标签、提醒和日期各自保留，不拼正文 |
| 夹子随当前页 | 展开工作叠放，翻到另一标签纸张 | 夹子和元信息颜色跟随该张；元信息先分组后标签 |
| 独立筛选 | 右击纸张 → 只看当前分组；再筛选标签；清分组后只筛标签 | 两条件同时启用取交集；只筛标签可跨分组。只显示匹配成员，退出恢复原叠放、位置和重量 |
| 顶部搜索 | 右击 → 筛选标签…；输入长标签名、清空，切换中英文及浅深色 | 顶部单行轻搜索，提示所有标签或当前组；“全部标签”固定。最多六行内部滚动，少结果缩短，屏内可操作 |
| 管理入口和保护 | 日历 → 更多 → 分组与标签；逐个打开三个页签 | 顺序分组、标签、已移除；前两页显示全部对应项。已移除项灰态且小字提示，默认通用/未分组受保护 |
| 已移除选择 | 移除一个不用的测试分类 → 已移除；尝试恢复 | 标签色点与分组文件夹保留，两个区域独立滚动，只提供恢复选用，恢复后原内容分类关系保持 |
| 窗口位置 | 挂绳展开后打开日历/管理/设置，拖到有效位置，再关开及返回日历 | 默认同屏避纸夹，尽量在下方约16DIP，屏边约12DIP；不溢出。有效手动位置与日历搜索、日期、滚动、编辑状态保留 |
| 窗口复用 | 连续重复点击日历和管理入口，再来回返回 | 复用窗口和进行中请求，不叠加重复窗；保持状态。隐藏约30秒后的回收与正常重开可用 |
| 原可见性 | 打开新建输入草稿；再到日历及管理 | 新建允许收起挂绳；日历与管理保留挂绳参考，设置和新建共存，草稿保留 |
| 详情翻页 | 打开多张叠放，浏览/编辑分别看底部；点击页码并选标题 | 正文之后是居中轻量翻页，再下面是操作图标。单张不显示翻页；标题列表可直接跳转，编辑与保存保护保持 |
| 铃铛与图标 | 详情、日历详情逐个点击底部铃铛/复制/编辑/收起/拆分/更多 | 铃铛第一位，顺序一致；同类图标18px且点击区可用。窄窗文字清晰，悬浮/完整浮层可读完整提醒和拒绝原因 |
| 合并入口与目标 | 右击工作组纸张 → 整理 → 合并…；查找挂绳和日历目标 | 打开独立小面板，没有第三层目标原生菜单。当前组全部兼容目标都能找到，不局限当前夹子数；排除自己/源整夹/删除/旧不兼容混组 |
| 合并搜索与三列 | 搜索目标标签全名、名称、正文（含叠放隐藏成员） | 同一目标叠放只列一次。左色点+标签·名称，中张数，右挂绳或创建日期。长名各自省略可悬浮；有跨年旧念头时显示完整YYYY-MM-DD（无需手改数据日期）；不挤张数/日期，不缩字号 |
| 只取当前源 | 先给源夹放两张，右击当前张合并到挂绳目标 | 仅当前纸张转移，源其他成员留原处，目标完整叠放仍在挂绳；日历即时同步张数和挂着状态 |
| 合并到日历 | 同样操作但选日历目标；关软件重启 | 完整目标叠放留日历且持久，能翻页和选标题；源释放夹位可补其他原有候选，手动日历叠放不自动补位 |
| 日历拆分与整体挂上 | 日历叠放详情 → 拆分；再选择叠放挂上或满容量换上 | 拆分仍留日历；主动挂上/换上处理完整叠放。日期格按真实纸张计数，每张原创建日期不变 |
| 显示全部 | 手动合并到日历后，右击挂绳 → 显示全部 | 只清筛选，不把手动日历叠放拉回挂绳 |
| 一级菜单 | 右击纸张，分别看无撤销和成功挂上/换上后 | 常态六项：新建、只看分组、筛选标签、显示全部、Thoughtline 日历、整理；成功且仍有效时增加一项挂上/换上撤销；没有查看全文，纸张展开图标仍保留 |
| 整理与撤销 | 整理 → 收起/合并/拆分/自动整理，每次再打开菜单撤销 | 顺序收起、合并…、拆分叠放、自动整理，分隔后最多一个有效最近撤销。挂上/换上撤销只在一级，不重复、不多步历史；收起仅当前张 |
| 共享撤销与后续修改 | 在日历挂上后到挂绳撤销；合并后再合法改正文或拆分另一日历叠放再撤销 | 同一有效记录跨入口共享；有效撤销恢复关系、位置、状态及补位副作用，不覆盖随后合法修改；失效记录隐藏。仅浏览/保存/复制/筛选或失败操作不生成新撤销 |
| 删除恢复与改组 | 日历叠放删除一张再恢复；编辑其中一张换分组 | 最近删除在日历内；恢复合法原归属，改组必要确认仍出现，其他成员不丢失；旧混组历史数据兼容不等于开放新跨组合并 |
| 保存/输入法/关闭 | 正文输入中文，候选词未完成时翻页/离开；完成输入后正常关闭 | 不误提交候选，不丢草稿；保存失败保留窗口和原数据。合并→标题跳转→撤销后无活动编辑时可正常关闭 |
| 旧功能回归 | 新建草稿同时开设置；联系栏；TXT/DOCX导出及JSON备份 | 已交付设置、边框、联系、移除灰态和导出保持；TXT/DOCX仍极简阅读文档，JSON完整备份，取消导出不产生文件 |
