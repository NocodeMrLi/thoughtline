# Thoughtline 0.0.31 操作验证报告

0.0.31已通过双端技术验证。构建/tag源码 9d4ea599e71b4cb85707145ed6ca46e674cfafb0；Windows完整运行 38369828529，第1次执行成功。Mac356单测通过、4项Windows专用跳过；Windows360全部通过，类型与构建通过。Mac源码6套及实际DMG9套回归、Windows完整源码/实际包及NSIS安装、重装、普通卸载保数据验证通过。两端源和实际包各17项导出行为、8个中英浅深宽窄菜单场景通过；340份构建输入同源。

本次第五轮 R5-17 将“导出备份”改为极简“导出”菜单：导出 TXT、导出 DOCX、备份数据。沿用已确认的页面、配色、联系栏和操作逻辑。

## 可以照着操作

升级前用原版导出一份完整备份，正常退出旧版，再安装对应系统的新包。

| 操作 | 预期结果 |
|---|---|
| 日历 → 更多 → 存储与设置 → 数据与备份 → 导出 | 按钮旁出现三行小菜单，没有新页签、复选框或额外确认按钮 |
| 点击“导出 TXT”，选择文件名和保存位置 | 保存一个 UTF-8 文本文件，可用记事本或文本编辑打开；中文、emoji、段落和空行保留 |
| 点击“导出 DOCX”，选择保存位置 | 保存一个标准 Word 文档，可交给 Word/WPS 等支持 DOCX 的软件打开 |
| 比较同一条念头的原文和导出文件 | 依次包含分组、标签、名称、完整正文；按分组整理，同组按创建时间排列 |
| 检查同名念头、未填名称和已收起念头 | 同名分别保留；未填名称显示“未命名念头”，不改软件内的名称；已收起内容也包含 |
| 在日历搜索/切换月份后再导出 | 仍导出全部有效念头，不受当前筛选影响；已移除分类下的有效内容仍保留 |
| 打开新建、输入草稿，再在设置导出 | 两窗共存，草稿保留；TXT/DOCX不混入草稿或最近删除，完整备份仍保留它们 |
| 保存对话框点击取消，再次打开导出 | 不生成文件，界面可继续使用；保存失败会提示，原有目标文件保持 |
| 点击“备份数据” | 原有完整数据备份流程保持；JSON与校验清单用于恢复，不与可阅读文档混放 |
| 切换中文/英文、浅色/深色并缩窄窗口；用方向键、回车和 Esc 操作 | 三行文字清楚、菜单在窗口内、原联系栏保持；Esc关闭菜单并返回导出按钮 |

TXT/DOCX用于阅读、整理和分享；要保留草稿、删除状态及恢复所需完整数据，使用“备份数据”。本轮不增加 PDF 导出或文档导回功能。

## 验证与边界

Mac实际DMG源码/asar/签名摘要一致；DOCX经过独立ZIP/XML检查与macOS文本读取器回读。系统保存对话框在自动测试中截获选择结果，实际文件仍通过真实IPC与文件系统生成；包含取消、权限/空间错误、已有文件保全、非法调用和并发请求检查。DOCX独立解包/XML检查与Mac文本读取器回读不等同于Windows Word/WPS实机排版验收。个人设备文件选择器、Office/WPS显示、物理输入法/DPI/多屏体验仍按上表确认，formalAcceptance/physicalAcceptance保持false。

早期Windows两次分别在旧自动整理初始窗口URL、仅标题详情自动保存等待处超时；原日志和ZIP均保留。后续诊断发现旧自动整理用例误用已回收的隐藏窗口，31秒确定性红→绿验证后改为从正常入口重开；不改生产或原功能断言/超时门槛。最终完整门禁结果另附。Mac最终DMG与九套已验证候选的asar和编译输出完全相同，并在最终DMG再次通过导出17项/8场景。
