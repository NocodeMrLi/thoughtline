# R5-17 极简念头导出（2026-10-13获准）

用户认可第二版极简草图并明确“执行吧”；本合同取代第一版带页签/范围复选框的大面板方案。基线0.0.30/main add6b22；直接main实施，沿用双端验证、私有安装包、推送与自有垃圾清理授权。当前状态：已完成。

## 界面与数据合同

- 数据与备份页原“导出备份”改“导出”带小下箭头；点击出现三行小菜单：导出 TXT、导出 DOCX、细分隔线后的备份数据。位置在按钮下方，越界时避让。无标题、页签、复选框或第二个确认按钮。
- 点击文档格式直接打开系统保存对话框；取消、Esc和外部点击自然返回。菜单支持键盘、焦点回到触发按钮、中英/浅深/窄窗；保留当前设置布局和底部联系栏。
- TXT/DOCX各生成一个可直接阅读的文件。按分组归集，同组按创建时间稳定排序；每条依次含分组、标签、名称、完整正文。使用现有真实分类名称，同名念头分别导出；未填名称仅在文档显示“未命名念头”，不写回源数据。保留中文、emoji、段落、空行和长正文。
- 文档固定导出所有有效念头（hanging和archived），包括已移除分类下的有效内容；不受当前日历月份/搜索过滤影响。不混入未完成草稿或最近删除。草稿及删除状态继续由“备份数据”保存，无新增范围控件。
- 导出取执行时一致快照，沿用现有未保存/输入法/IO保护；新建与设置可共存。导出不会更改当前数据位置、分类、念头或旧备份。取消不生成文件，失败不损坏原有文件，成功信息包含实际保存位置。
- “备份数据”继续现有JSON、manifest校验和草稿检查点流程；不改备份格式、不向恢复目录混放TXT/DOCX。已有恢复兼容性保持。
