## 六项照操作检查

1. **小面板拖动和关闭**
   前置：挂绳有可筛选标签和同组兼容合并目标。右击当前纸张→筛选标签…，或整理→合并…。预期首次尽量避纸张放在下方，不足时适配屏内；顶部细条可以拖动，搜索输入和选项可正常点击。两面板无叉号，均有Esc关闭提示。按Esc或点击面板外关闭；成功选中也关闭。拖到有效位置再打开保持位置。输入缩小结果再清空，面板恢复自然高度，最多六行内部滚动，不重新跳位置。取消不改筛选或叠放。

2. **复制反馈**
   从挂绳展开当前便签，以及日历点击卡片，两处分别试一次。悬停复制按钮看到“复制正文”，点击后原按钮上方显示“已复制”，约1.6秒消失；重复成功重新计时。左下角不再出现复制成功消息，窗口不撑大，复制保持完整正文。复制失败应显示明确错误，不能出现成功提示。

3. **日期和找到收起/合并目标**
   挂绳纸张底部留白左侧可见创建日期；翻页时随当前张变化，同年10月13日，跨年2025/10/13。点击日期进入当日列表并高亮所属卡片，首屏外目标也定位到可见范围；小窗口显示标题和纸张可见部分，不要求超高纸完全放下。整理→收起后，源位置附近短暂出现日期/查看链接；合并到日历后出现查看目标链接，约4秒。点击查看进入目标代表纸张日期。各纸原日期、正文和分类不因操作改变。

4. **日历显示真实叠放，拆分回原列表**
   同组两张合并后打开创建日期列表：同一天只显示一张叠放卡片，有轻叠边和右下角“2张”；月历当天仍计2张纸。若两张跨日期，两天都能找到同一完整叠放，每天仍计各自纸张数；悬停张数显示“当日1张/共2张”。单张不显示叠放数量。点卡片进入详情可翻页和标题列表跳转；拆当前张/更多→全部拆开后回到原日期/搜索列表，保留日期、搜索、状态及滚动，必要扩展加载范围使拆开卡片直接可见，不返回月历。重启后叠放/独立创建日期保持。失败或组合输入未完成时留当前详情和原文。

5. **恢复反馈**
   日历更多→最近删除→点开一条念头。悬停恢复按钮显示“恢复念头”，点击真实成功后原按钮位置上方显示“已恢复”，约2.5秒消失。恢复按钮被普通操作替换，提示仍完成展示；留当前念头详情，窗口尺寸不跳变，左下角无恢复成功消息。绳已满则提示“已恢复 · 留在日历”，筛选隐藏则“已恢复 · 当前筛选未显示”，约4秒。错误仍明确显示，不冒报成功。

6. **搜索标签/名称/正文**
   准备不同标签下有相关名称和关键词的挂着念头。打开筛选标签，依次输入标签名、念头名称、正文关键词。预期三者都能找到相应标签，隐藏叠放成员也能命中；同标签只一行。标签名命中在前、名称其次、仅正文最后；每档按匹配念头创建时间新到旧排。限定分组时不混其他组，已收起/最近删除不混入。选中标签筛选该标签全部挂着内容；搜索词不变成正文筛选条件。清空搜索回原默认顺序，全部标签固定，数量仍是标签完整挂着纸张数。
