# 设计13：真实弹簧夹实施记录

2026-10-09用户明确要求依据本机13设计与概念图复现夹子，覆盖先前“设计就行”的边界。生产夹子现为小尺寸矢量木质弹簧夹。原概念图留在本机笔记目录；没有复制或上传图中背景、品牌素材或放大装饰。

| 原设计要求 | 实现 | 验证与边界 |
|---|---|---|
| 两片夹臂、开口、斜切夹口 | Clothespin.tsx独立双臂路径、侧面与下夹口 | clothespin-native.json，12张本地完整截图；小尺寸矢量为概念结构解释，用户真实性评审待验 |
| 半哑光木质、倒角与少量纹理 | 同色漆面、浅边/暗侧与减化木纹 | 1×/2×实际DPR画面，浅/深中性背景 |
| 银色卷簧与压丝 | 金属多层曲线、双圈卷簧和横向压丝 | 实际SVG与截图，未增加图片资源 |
| 18×38视觉，24×44命中 | SVG18×38；peg-button尺寸不变 | DOM几何断言；卡片仍160×112 |
| 绳、夹子和纸连接协调 | 同一固定抛物线锚定；夹口跨过纸顶边 | 空/3/24张路径相同；夹口与纸边实际重叠；绳核2.2DIP、低幅暗影，不使用粗麻绳 |
| Codex蓝/Claude橙/Cursor柔紫/通用暖灰 | 新数据默认#4C90D9/#D79551/#9574CE/#A0A3AA | agentPalette测试先失败后通过；既有颜色全部保留，无法区分用户选回旧默认色，故不自动迁移 |
| Gemini/WorkBuddy只作样板 | 支持现有自定义Agent颜色，不强制预置 | 无新增API连接或固定标签 |
| 轻微悬停、110ms夹臂内压/释放 | hover只调高光；按压/真实拖动状态驱动双臂±2° | 协议press/release及group工作流；不动卡片尺寸，不持续摆动 |
| 减少动态效果中止夹臂动作 | CSS系统/设置及SVG运行时属性同时约束 | 半途系统偏好切换后transform为none；显隐无位移，稳定无rAF |
| 常态只有绳、夹子、便签 | 原分类筛选/查找工具条已移除 | 无替代图标行；临时功能及托盘保留 |
