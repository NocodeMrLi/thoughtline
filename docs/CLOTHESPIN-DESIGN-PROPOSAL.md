# 晾念头：真实弹簧夹造型与Agent配色设计

2026-10-09，用户明确要求：夹子像真实夹子，色彩丰富，Codex蓝、Claude橙；本轮“设计就行”，先交造型方案，不修改生产夹子资产或默认配色。与12干净挂绳方案一起评审。

## 推荐造型

彩色半哑光漆面木质弹簧晾衣夹。必须看出两片夹臂、开口、斜切夹口、银色卷簧和压丝，真实地夹住绳子与纸边；不再用圆角竖色条模拟夹子。边缘倒角、少量木纹和暗侧面提供体积；金属弹簧给细小高光，不使用夸张镜面或发光塑料。

视觉建议18×38DIP，交互命中仍24×44DIP。小图保留双夹臂轮廓、银簧和夹口，其余木纹减化；放大样板展示材质，不把写实大图原封不动缩成模糊18像素图。矢量与多倍率小尺寸样片分别验证。纸边压在夹口内，夹子锚点落于当前绳曲线，不像悬空的标签柱。用户本轮对真实性的要求优先于旧12×34竖条视觉。

采用同一漆面材质和结构，不同Agent换主色；同Agent的夹子颜色保持一致。轻微明暗层次属于立体材质，不随机改变每个Codex夹子的颜色，避免分类含义混乱。Gemini/WorkBuddy仅为自定义Agent样板，不新增Agent API连接或强制添加预置项。

Agent名仍在便签里，识别不只靠颜色。标签文字保持主题可读色，不能直接用浅夹子颜色当小字。用户可以自定义Agent颜色；后续切换新版默认色时不能擅自覆盖用户已选择的颜色。

## 动作反馈

悬停轻微增强边缘和夹口高光，不放大卡片或挪动点击目标。抓取时两片上夹臂轻微内压、下夹口轻开，90–120ms；沿绳拖动主体保持稳定，不连续晃动。释放回夹口原态，需绑定真实操作完成；合夹沿用600ms确认环。小尺寸动作以后应基于矢量夹臂变换验证，不为“夹一下”增加无意义按钮。

减少动态效果时取消夹臂运动，保留静态按压/描边反馈和全部操作。纸、绳和夹子的坐标应来自同一几何；夹子动画不制造超过合法间距的便签碰撞。
