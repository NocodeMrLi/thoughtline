# 独立设置窗口接手核验与交付

## 目标与范围
保留 zcode 工作区，只调整独立设置窗口、托盘和夹子入口；删除日历设置入口；保持原功能/界面。按用户授权完成 Mac/Windows 受影响链路、清理、main 推送、双端测试包、修复记录和操作验收报告。Microsoft Store 提审不在本次范围。用户追加：不使用 Actions，本机构建后上传发布，Windows 由用户实测。

## 阶段
- [x] 核对当前实现/旧证据并定位 storage 未完成原因
- [x] 最小修复与 Mac 定向回归
- [x] 本地构建 Windows x64 包并核验包内文件；无 Windows 环境，用户确认运行待其实际测试
- [x] 整理证据与清理，提交推送 main，交付双端测试安装包
- [x] 更新主文/bug 记录，准备本窗口逐项操作验收报告

## 原则
旧测试数字不冒充当前结果；CI 原生与物理用户验收区分；仅清理归属明确数据，不触碰用户安装及真实便签。

## 错误记录
- 全局刷新 hook 指向旧目录不存在，按已知实际文件夹读取协作文档；两篇长文读取输出超长，后续按章节读取。
- exec 未指定 workdir 时旧 cwd 不存在；全部后续显式有效目录。

用户最终追加：完成后本机生成最新 Store MSIX，直接放桌面 Thoughtline微软商店上架材料，明天由用户上传；不替其送审。
