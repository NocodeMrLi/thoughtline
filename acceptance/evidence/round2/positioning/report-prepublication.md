# Thoughtline 0.0.20 定位升级与标题修复完成报告

## 本版完成范围

| 项目 | 实现与验证 |
|---|---|
| 面向工作与生活 | 应用拥有的窗口标题、菜单、表单、提示和错误统一使用标签口径；内部稳定标识及用户自定义文字不改写。 |
| 六个精简预置 | 新用户为通用、生活灵感、工作记录、直属领导、同事、Codex。旧用户不强加预置、不改名换色；保留原草稿、ID、正文、项目、顺序和创建日。 |
| 中英标签显示 | 未改名的预置支持英文显示；自定义或已经改名的标签保持原文。新建窗“标签：”，管理页“Thoughtline标签／新增标签”。 |
| 筛选语义 | “只看 {标签名称}／显示全部标签／筛选标签”，勾选反映筛选；恢复所有标签不会挂上已收起念头。 |
| 日历三种状态 | 全部状态／挂着／未挂上。未挂上包含直接保存和主动收起，旧容量溢出也纳入；叠纸每张计数，草稿和删除项不计。 |
| 状态不误写 | 按当前可用挂绳容量推导，过滤隐藏的正常已分配夹子仍算挂着；只读浏览、搜索、状态筛选和尺寸变化不改写内容、日期、位置或关系。 |
| 保留先前功能 | 日历开放时挂上立即显示、容量前置、换上、自动整理、合并拆分、紧凑更多菜单移开关闭、设置返回和中英昼夜等保留。 |
| 标题自由编辑 | 两种编辑入口慢速退格删空后，不被正文首行反复覆盖；直接输入新标题，自动保存、焦点、光标和组合输入保护保留。持久层原有空名称生成规则不变。 |
| README | 七种文档定位、标签和状态描述以及0.0.20下载入口已更新；图标、徽章、语言链接和醒目下载排版保留，展示图/GIF继续按用户要求后置。 |

## 失败与未测范围

新默认项导致旧测试夹具依赖失效，改成显式旧数据夹具，不重置产品旧数据或削减断言；保存回执早于DOM提交的测试等待已修正；新增实际包监督器曾未传播失败退出码，已修复并保留原失败证据。标题测试重复“完成编辑”选择器改为具体编辑区域；保留慢速删空、光标、IME保护、数据与重启断言。

Mac启动器改为移除继承的开发运行时环境变量，而非设置空值；本版固定DMG/asar/版本检查与已有App运行保护通过。历史LaunchServices退出停滞证据保留，干净环境系统正常打开/退出仍未独立验证，不能由Playwright直接启动正常退出代替。没有改动真实安装或关闭用户App。

双端实体输入法、DPI100/125/150%、多屏、Mac桌面真实菜单外点、真实接收软件重复外拖、动画与材质手感仍需独立实机验收。微信、QQ浏览器豆包、WorkBuddy结果仍是用户反馈，未冒称独立复现。原生Liquid Glass未实现，纸保持哑光。
