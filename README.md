Thoughtline 是一款面向 macOS 和 Windows 的轻量桌面念头工具。需要时，在屏幕顶边呼出晾衣绳；写下、整理、取用，再回到手头的事情。

## 功能

- **标签与分组**：各编辑窗口统一搜索与创建；长按整理后点叉移出选择列表。管理页分标签、分组、已移除三页，恢复区独立滚动，空分组可保存。
- **更容易新建**：夹子或便签右键即可新建念头；写作与日历可以共存，分类菜单不撑大新建窗口，写作时仍可从顶边呼出挂绳。
- 挂绳样式菜单显示真实棉绳纹理和藤蔓枝叶；展开和日历详情的标题、正文保留独立边框及安全区，颜色跟随夹子和纸张。 拖动夹子时，藤蔓枝叶和卷须保持原位。
- **随手记下**：快捷键打开新建窗，记录标题、正文和标签；未提交内容可以保存为草稿。
- **晾在桌面**：常驻界面只有绳、夹子和纸张。夹子正面夹住薄纸，新念头默认归属“通用”。
- **选择舒适数量**：日历顶部三个点 →「存储与设置」选择 4／6／8 个夹子，默认 6 个；便签随屏幕等比例适配，4 个档位只适度放大。满绳保存的新念头在腾出位置后按创建时间由新到旧自动补位；旧未挂记录和主动收起的念头仍由你决定何时挂上。
- **搭配自己的挂绳与纸张**：日历顶部三个点 →「存储与设置」→「外观」。经典细绳可自由调色；编织棉绳保留天然棉色，轻藤蔓保留自然绿色，夹子继续跟随标签颜色。纸张提供五种柔和预设纸色，以及空白／细横线／轻虚线；先预览，点「应用」才保存。设置分为外观、操作、数据与备份，取消或返回不会保存预览。 分类下拉选择，完整预览和应用按钮同时可见，调整时无需上下滚动。
- **顺手整理**：拖木夹移动整组，拖纸张上缘抽出一张；右键“合并”选择兼容夹子，“拆分”抽出当前一张。间距零散时拆分会自动腾位；“自动整理”按左右顺序收拢间距，整理可撤销。
- **原地修改**：在展开窗或日历里直接编辑，短暂停顿后自动保存；组内翻页即时显示。 阅读和编辑都使用标签色边框，标题与正文跟随所选纸色。
- **按日期回看**：Thoughtline日历支持日、月、年浏览、搜索与状态筛选；未挂上的念头仍可找到。
- **留下退路**：删除念头进入最近删除，可以恢复；删除项目只解除归属，保留念头内容。 原来挂着的念头优先回原夹或空位；绳满时先恢复日历，可自行换上。
- **取用正文**：显式复制或从正文拖出纯文本，原纸张保留，不自动发送。
- **自己管理数据**：念头保存在本机，可查看实际目录、更改保存位置、导出独立备份。
- **中英与昼夜**：首层窗口即可切换中文／English和白昼／夜间外观，也可跟随系统；纸张保持柔和、清晰的纸感。
- **绳满也能继续记**：新建时可保存，或在当前窗口选择“换上”；旧念头收起并保留。日历重新挂上立即显示到绳上；更多菜单移开鼠标即可收起。
- **标题独存与提醒**：标题或正文至少填写一项，正文可留空。新建和详情小铃铛设置单次提醒，日历同步显示；到时使用系统通知，点击打开对应念头。通知需系统允许；应用彻底退出期间不会准时提醒，重启集中提示错过的提醒。系统通知不可用时，用顶部不抢焦点的轻提醒条兜底，点击查看，不另开窗口。

## 下载与安装

当前版本向有仓库访问权限的成员开放。到 [Releases](https://github.com/NocodeMrLi/thoughtline/releases/tag/v0.0.30) 下载安装包、隔离启动入口和 `SHA256SUMS`；每版提供对应构建来源与校验清单。

| 平台 | 当前安装包 |
|---|---|
| macOS · Apple Silicon | arm64 · DMG |
| Windows | x64 · EXE（NSIS） |

安装或升级前，正常退出应用并备份现有数据。项目不安排商业签名证书、平台认证或公证；用户按系统正常信任提示安装使用。Mac 保留本地 ad-hoc 签名，Windows 包未签名。签名状态与软件的成熟度、验收结果分开说明。当前不提供自动更新。

## 开始使用

1. 按 `Control + Alt + N` 写一个念头；Mac 对应 `⌃ + ⌥ + N`，可在设置中修改。
2. `Enter` 换行；Mac 用 `⌘ + Enter` 提交，Windows 用 `Ctrl + Enter` 提交；`Esc` 保存草稿并收起输入窗。
3. 将鼠标移到屏幕顶边，呼出绳上的念头。移向或操作纸张时保持展开，离开操作区域后收起。展开纸张可阅读、复制、编辑或收起。
4. 从日历回看、搜索已收起的念头，或在最近删除中恢复内容。

标签可以表示用途、角色或工具，例如生活灵感、工作记录、直属领导、同事或 Codex；也可自己添加日报、设计方案、客户等标签。新安装提供六个精简标签，旧用户的标签与颜色保持不变。Thoughtline日历用“全部状态／挂着／未挂上”筛选；“未挂上”包含直接保存和主动收起的念头，旧数据因绳上容量而未显示的记录也能找到。向其他软件取用内容时，由用户复制或拖动正文；目标输入框的实际接收效果仍需分别验证。

## 数据与备份

日历设置显示实际保存位置。迁移先复制并校验，再切换目录；旧副本保留。导出备份是独立副本，不改变当前位置。恢复流程见 [数据安全说明](docs/ROUND1-DATA-SAFETY.md)。

当前数据格式为 schema3。旧版 `0.0.16-preview.6` 不能直接读取新格式；降级前保留新数据，并使用升级前备份在独立目录验证。升级前备份不包含之后的修改。

## 开发

使用 **Node.js 24.19.0 或更高的 24.x 版本**。

```bash
npm ci
npm run dev
```

```bash
npm run verify
npm run package:mac
npm run package:win
```

`verify` 执行类型检查、单元测试与构建；平台包在对应系统构建。技术栈为 Electron、React、TypeScript 和 Vite。

当前版本已完成适用自动检查与包验证。真实 Mac／Windows 输入法、DPI、多屏、焦点与微信、豆包、WorkBuddy 等外部输入框仍待独立测试。应用界面支持中文与 English；新建、展开和日历窗口右上角可直接切换语言及日间／夜间外观，设置内可恢复跟随系统。上方七种语言链接提供 **README 文档翻译**，不表示应用支持七种界面语言。
